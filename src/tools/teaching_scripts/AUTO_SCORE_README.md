# 自动评分系统说明

## 功能概述

自动评分系统整合抄袭检测、质量评估和提交时间数据，自动生成学生实验成绩。

## 评分规则

### 1. 抄弊判定
- 相似度 > 80% → **抄袭** → 0分
- 相似度 ≤ 80% → **原创** → 进入质量评分

### 2. 质量评分（100分制）

| 评分项 | 满分 | 数据来源 |
|--------|:----:|----------|
| 团队协作 | 5分 | evaluations.json |
| 实验原理与认知 | 10分 | evaluations.json |
| 实验完成度 | 35分 | evaluations.json |
| 代码质量 | 30分 | evaluations.json |
| 实验报告质量 | 10分 | evaluations.json |
| 实验态度 | 10分 | evaluations.json |
| **总计** | **100分** | |

### 3. 等级划分

| 分数区间 | 等级 | 标签 |
|----------|:----:|------|
| 90-100 | A | 优秀 |
| 80-89 | B | 良好 |
| 70-79 | C | 中等 |
| 60-69 | D | 及格 |
| 0-59 | F | 不及格 |

## 使用方法

```bash
cd docs/teaching/2026-春季/汽服2302B班/scripts
python auto_score.py
```

## 输出文件

生成的Excel文件：`汽服2302B班_2026春季_实验成绩册_自动评分.xlsx`

包含以下信息：
- 排名
- 学号
- 提交时间
- 总分
- 等级
- 状态（原创/抄袭/未提交）
- 各项详细得分

## 数据依赖

系统需要以下数据文件：

1. **data/evaluations.json** - 学生质量评估数据
   - 包含每个学生的各项得分
   - 来源：自动质量评估系统

2. **SUBMISSION_TIMES** - 提交时间（内置）
   - 记录每个学生的提交时间

3. **PLAGIARISM_STUDENTS** - 抄袭学生列表（内置）
   - 相似度 > 80% 的学生

## 优点

1. **客观公正**：基于数据自动评分，避免人为偏见
2. **高效快捷**：一键生成所有学生成绩
3. **透明可查**：提供详细的各项得分
4. **减少误差**：避免人工计算错误

## 注意事项

1. **实验态度分**：目前默认给满分，需要教师根据实际出勤情况调整
2. **组长附加分**：需要教师手动添加
3. **特殊情况**：如有特殊加减分需求，可在生成后手动调整

## 更新抄袭学生列表

如需更新抄袭学生列表，编辑脚本中的 `PLAGIARISM_STUDENTS` 集合：

```python
PLAGIARISM_STUDENTS = {
    '23071140217', '23071140216', ...
}
```

## 更新提交时间

如需更新提交时间，编辑脚本中的 `SUBMISSION_TIMES` 字典：

```python
SUBMISSION_TIMES = {
    '23071140226': '2026-06-04 16:30:28', ...
}
```
