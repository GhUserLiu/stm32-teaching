# LED不亮 - 故障排查指南

## 🔍 已生成测试文件

**文件**: [build/Test6/Debug/Test6.hex](build/Test6/Debug/Test6.hex)

**功能**: LED闪烁测试
- LED0 (PF9) 闪烁
- LED1 (PF10) 闪烁
- 两LED同时闪烁

---

## ✅ 硬件检查清单

### 1. BOOT跳线设置 (最重要!)

```
BOOT0 跳线帽必须接 GND (0V)
BOOT1 不连接或接GND
```

| BOOT0 | BOOT1 | 启动模式 |
|-------|-------|----------|
| 0V | X | ✅ Flash启动 (正确) |
| 3.3V | 0V | ❌ 系统存储器启动 |
| 3.3V | 3.3V | ❌ RAM启动 |

### 2. 供电检查

用万用表测量：
- **3.3V引脚** 应该有约3.3V电压
- **GND** 应该是0V
- **VDD** 引脚应该有电压

### 3. LED连接检查

LED是共阳极，连接方式：
```
3.3V → LED限流电阻 → LED+ → LED- → MCU引脚
```

**PF9/PF10输出低电平时LED亮，高电平时LED灭**

用万用表测试：
- LED亮时：PF9/PF10 应该约 **0V**
- LED灭时：PF9/PF10 应该约 **3.3V**

### 4. 烧录检查

确认：
- 烧录地址：**0x08000000**
- 烧录完成后**复位**芯片
- 重新上电

### 5. 串口调试 (可选)

如果连接了串口：
- PA9(TX), PA10(RX)
- 波特率：115200
- 应该有启动信息输出

---

## 🛠️ 测试步骤

### 方法1：观察LED

烧录后应该看到：
1. LED0 闪烁
2. 然后LED1 闪烁
3. 然后同时闪烁
4. 然后同时熄灭
5. 循环重复

### 方法2：万用表测试

测量PF9/PF10引脚：
| 状态 | PF9电压 | PF10电压 |
|------|--------|----------|
| LED0亮 | 0V | 3.3V |
| LED1亮 | 3.3V | 0V |
| 都亮 | 0V | 0V |
| 都灭 | 3.3V | 3.3V |

如果电压正确变化但LED不亮 → LED硬件问题

---

## 📞 如果还是不亮

请检查：

1. **LED方向**：LED有正负极，装反了不亮
2. **限流电阻**：应该有约220Ω-1kΩ电阻
3. **MCU型号**：确认是STM32F407ZGTx
4. **晶振**：如果使用外部晶振，检查是否焊接

---

## 💡 简化代码说明

当前代码完全使用寄存器操作，不依赖HAL库：

```c
// 使能GPIOF时钟
RCC_AHB1ENR |= (1 << 5);

// 配置PF9/PF10为输出
GPIOF_MODER = ...;

// LED闪烁
while(1) {
    GPIOF_ODR &= ~(1 << 9);   // PF9 = 0 (亮)
    delay();
    GPIOF_ODR |= (1 << 9);    // PF9 = 1 (灭)
    delay();
}
```

这是最简单的测试，如果这个不亮，其他复杂版本也不会亮。
