# Test6: 智能灯光控制系统 - 问题分析与解决方案

## 📋 实验任务概述

### 功能要求
- **4种工作模式**: 关闭、左转、右转、双闪
- **KEY0 (PE4)**: 循环切换模式 (关闭→左转→右转→双闪→关闭)
- **KEY_UP (PA0)**: 紧急双闪切换 (按下进入双闪，再按恢复原模式)
- **LED0 (PF9)**: 左转向灯，共阳极低电平点亮
- **LED1 (PF10)**: 右转向灯，共阳极低电平点亮
- **中断优先级**: KEY_UP优先级高于KEY0，可打断模式切换

## 🐛 原代码问题分析

### 问题1: 致命的循环条件错误 ❌

**位置**: `Test6/main.txt` 第177行

**错误代码**:
```c
for(volatile int i=0; i<0; i<1000000; i++);  // 条件永远为false!
```

**问题**: 循环条件 `i < 0` 永远为假（因为i从0开始），导致循环体永远不会执行，程序卡死在这一行。

**修复**:
```c
for(volatile int i=0; i<1000000; i++);  // ✅ 正确的延时循环
```

---

### 问题2: 时钟配置与硬件不匹配 ⚠️

**位置**: `Test6/main.txt` 第214行

**错误代码**:
```c
RCC_OscInitStruct.PLL.PLLM = 25;  // 假设25MHz晶振
```

**问题**: 根据任务书，开发板使用**8MHz外部晶振**，但代码配置为25MHz。这可能导致SystemClock_Config失败，使系统运行在不正确的时钟频率下。

**修复**:
```c
RCC_OscInitStruct.PLL.PLLM = 8;   // ✅ 8MHz晶振
```

**计算公式**: 8MHz ÷ 8 × 336 ÷ 2 = 168MHz

## 📚 教学要点

### 1. 循环条件的正确写法
```c
// ❌ 错误: 永远不会执行
for(int i = 0; i < 0; i++);

// ✅ 正确: 执行1000000次
for(int i = 0; i < 1000000; i++);
```

### 2. STM32时钟配置
- 必须根据实际硬件晶振频率设置PLLM
- 计算公式: `SYSCLK = HSE / PLLM * PLLN / PLLP`

### 3. 中断优先级
- 数值越小，优先级越高
- 抢占优先级高的可以打断优先级低的中断
- KEY_UP (优先级0) 可以打断 KEY0 (优先级1)

### 4. 共阳极LED控制
- 低电平点亮 (GPIO_PIN_RESET)
- 高电平熄灭 (GPIO_PIN_SET)

## 📞 故障排查

如果LED仍然不亮，检查：

1. **BOOT跳线**: BOOT0应接GND
2. **供电**: 3.3V电源正常
3. **烧录地址**: 应为0x08000000
4. **万用表测试**: 测量PF9/PF10引脚电平变化
