# 按键LED测试案例

## 测试目的
验证按键和LED硬件连接是否正常。

## 测试功能

| 按键 | LED | 效果 |
|------|-----|------|
| KEY0 (PE4) | LED0 | 按下闪烁（亮1s灭1s），松开熄灭 |
| KEY_UP (PA0) | LED1 | 按下闪烁（亮1s灭1s），松开熄灭 |

## 配置说明

### 按键配置
两个按键都配置为**低电平触发 + 上拉**：
- KEY0 (PE4): 上拉，按下时变低
- KEY_UP (PA0): 上拉，按下时变低

### LED配置
- LED0 (PF9): 低电平亮
- LED1 (PF10): 低电平亮

### 时序参数
- 主循环延时: 5000
- 闪烁间隔计数: 500
- 实际闪烁周期: 500 × 5000 = 2,500,000 次循环

## 预期现象

1. 上电后，两个LED都熄灭
2. 按住KEY0：LED0以1s亮、1s灭的频率闪烁
3. 松开KEY0：LED0熄灭
4. 按住KEY_UP：LED1以1s亮、1s灭的频率闪烁
5. 松开KEY_UP：LED1熄灭

## 故障排查

### KEY0无反应
- 硬件上KEY0可能不是PE4，检查接线
- 或KEY0是高电平触发，修改代码

### KEY_UP无反应
- 硬件上KEY_UP可能不是PA0，检查接线
- 或KEY_UP是高电平触发，修改代码

### 闪烁太快/太慢
- 调整 `Delay(5000)` 值
- 调整 `interval = 500` 值

## 使用方法

将 `test_key_led.c` 替换 `main.c` 编译烧录即可。
