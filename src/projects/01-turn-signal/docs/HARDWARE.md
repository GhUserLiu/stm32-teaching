# STM32F407 转向灯系统 - 硬件使用说明

## 1. 引脚映射表

| 功能 | 端口-引脚 | 方向 | 默认电平 | 触发/点亮电平 | 说明 |
|------|-----------|------|----------|---------------|------|
| LED0 | PF9 | 输出 | 高 | 低电平亮 | 左转向灯 |
| LED1 | PF10 | 输出 | 高 | 低电平亮 | 右转向灯 |
| KEY0 | PF4 | 输入 | 低 | 高电平触发 | 模式切换键 |
| KEY_UP | PA0 | 输入 | 高 | 低电平触发 | 双闪开关 |
| PB0 | PB0 | 输入 | 低 | 高电平 | 备用按键1 |
| PB1 | PB1 | 输入 | 低 | 高电平 | 备用按键2 |

## 2. LED硬件特性

### 2.1 LED类型
- **类型**: 共阳极LED（低电平点亮）
- **端口**: GPIOF
- **引脚**: PF9 (LED0), PF10 (LED1)

### 2.2 控制逻辑
```c
LED点亮: GPIO输出低电平 (0)
LED熄灭: GPIO输出高电平 (1)
```

### 2.3 GPIO配置
- **模式**: 输出模式 (MODER = 01)
- **输出类型**: 推挽输出
- **速度**: 低速
- **无上下拉**: LED驱动不需要

## 3. 按键硬件特性

### 3.1 按键类型说明
本系统使用**独立按键**，一端接GPIO，另一端接电源或地。

#### 低电平触发按键
- **连接**: 按键一端接GPIO，另一端接GND
- **GPIO配置**: 内部上拉电阻 (PUPDR = 01)
- **默认状态**: 高电平 (1)
- **按下状态**: 低电平 (0)
- **示例**: KEY_UP (PA0)

#### 高电平触发按键
- **连接**: 按键一端接GPIO，另一端接VCC
- **GPIO配置**: 内部下拉电阻 (PUPDR = 10)
- **默认状态**: 低电平 (0)
- **按下状态**: 高电平 (1)
- **示例**: KEY0 (PF4)

### 3.2 按键检测逻辑
```c
// 低电平触发检测
uint8_t is_pressed = !(GPIOx_IDR & (1 << PIN));  // 按下时为0，取反得1

// 高电平触发检测
uint8_t is_pressed = !!(GPIOx_IDR & (1 << PIN));  // 按下时为1
```

### 3.3 消抖处理
机械按键在按下/释放瞬间会产生抖动（约5-10ms），需要消抖处理：

```c
// 方法1: 延时消抖
if (Read_KEY()) {
    Delay(20000);           // 等待抖动结束
    if (Read_KEY()) {       // 再次检测确认
        // 按键确实按下
    }
}

// 方法2: 计数消抖
static uint16_t count = 0;
if (Read_KEY()) {
    count++;
    if (count > 10) {       // 连续检测10次
        // 确认按下
    }
} else {
    count = 0;              // 清零计数
}
```

## 4. 功能说明

### 4.1 工作模式
| 模式 | LED0 | LED1 | 触发条件 |
|------|------|------|----------|
| 关闭 | 灭 | 灭 | 默认/双闪关闭 |
| 左转 | 闪烁 | 灭 | KEY0切换 |
| 右转 | 灭 | 闪烁 | KEY0切换 |
| 双闪 | 闪烁 | 闪烁 | KEY_UP切换 |

### 4.2 闪烁时序
- **亮时间**: 1秒
- **灭时间**: 1秒
- **频率**: 0.5Hz

### 4.3 开机演示
- LED0闪烁3次后进入主循环

## 6. 修改触发电平示例

如需修改KEY0为低电平触发：

**步骤1**: 修改 [board.h](board.h)
```c
#define KEY0_TYPE       KEY_ACTIVE_LOW    /* 改为低电平触发 */
#define KEY0_PULL       GPIO_PULL_UP      /* 改为上拉 */
```

**步骤2**: 修改硬件连接
- 将KEY0按键另一端从VCC改接到GND

## 7. GPIO口使用汇总

```
GPIOA:
  PA0 (IN)  - KEY_UP, 上拉, 低电平触发

GPIOB:
  PB0 (IN)  - 备用按键1
  PB1 (IN)  - 备用按键2

GPIOF:
  PF4 (IN)  - KEY0, 下拉, 高电平触发
  PF9 (OUT) - LED0, 低电平亮
  PF10(OUT) - LED1, 低电平亮
```
