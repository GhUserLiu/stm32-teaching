## 二、问题背景

### 2.1 教学痛点

在《汽车微处理器原理与应用》等嵌入式课程教学中，我们面临以下挑战：

1. **批改工作量大** - 每个实验40+份报告，传统人工批改需8-10小时
2. **查重困难** - 学生抄袭手段多样（复制、改写、代码相似），难以识别
3. **反馈不及时** - 学生提交后需等待数天才能获得反馈
4. **评估标准不一** - 人工评分存在主观性，难以保证公平
5. **AI代写检测难** - ChatGPT等工具普及，学生可能用AI代写实验报告

### 2.2 解决思路

开发一套**智能评估系统**，实现：
- 自动化查重检测（文本+代码）
- 多维度质量评估
- 个性化反馈生成
- AI生成内容检测

## 四、技术实现详情

### 4.1 多算法融合查重

系统支持5种相似度计算算法：

| 算法 | 适用场景 | 特点 |
|------|----------|------|
| Sequence | 短文本精确匹配 | 基于序列匹配，快速准确 |
| Cosine | 长文本相似度 | TF-IDF余弦相似度 |
| Jaccard | 词语重叠度 | 集合相似度计算 |
| Levenshtein | 编辑距离 | 字符级别变化检测 |
| Hybrid | 综合评估 | 加权混合多种算法 |

**创新点：混合算法**
```python
# 可自定义权重配置
similarity = (
    text_score * 0.4 +      # 文本相似度
    code_score * 0.4 +      # 代码相似度
    semantic_score * 0.2    # 语义相似度
)
```

### 4.2 模板智能过滤

自动识别并排除实验报告模板中的公共内容（如标题、实验要求、评分表等），避免虚高相似度。

### 4.3 抄袭团伙检测

基于图论算法，自动识别多人互抄团伙：

```
学生A ──70%── 学生B
  │             │
 65%           68%
  │             │
学生C ──72%── 学生D

→ 检测为"4人互抄团伙"
```

### 4.4 6维质量评估

| 维度 | 权重 | 检查内容 |
|------|------|----------|
| 技术准确性 | 30% | GPIO配置、中断设置、状态机逻辑 |
| 内容完整性 | 25% | 实验原理、硬件连接、代码实现 |
| 分析深度 | 15% | 问题分析、解决方案讨论 |
| 写作质量 | 10% | 结构、格式、排版 |
| 代码质量 | 10% | 注释、命名规范、模块划分 |
| 原创性 | 10% | 抄袭风险评估 |

### 4.5 智能反馈生成

为每个学生自动生成个性化反馈报告（Markdown/HTML格式）：

```markdown
# 实验报告评分反馈

**学号**: 23071140201
**姓名**: 张三
**总分**: 85.5/100 (85.5%)
**等级**: B

## 各项得分详情

### ✅ 团队协作 (5/5)
- ✓ 成员基本信息完整
- ✓ 个人分工明确合理

### ⚠️ 代码质量 (18/30)
- ✓ 代码流程图清晰
- △ 关键代码完整规范 (部分)
- ✗ 代码注释详尽

## 技术要点检查
亮点:
- ✓ 正确说明LED0连接到PF9
- ✓ 中断配置参数正确

需加强:
- ✗ 缺少或错误: DWT消抖实现
- ✗ 状态机逻辑描述不完整
```

### 4.6 AI生成检测

基于统计特征检测AI生成内容：
- 句长分布分析
- 词汇多样性检测
- 语言模式识别
- 可信度评估

## 六、创新价值

### 6.1 技术创新

1. **多算法融合查重** - 5种查重算法（Sequence、Cosine、Jaccard、Levenshtein、Hybrid）组合使用，可根据不同场景选择最优算法，准确率显著提升

2. **模板智能过滤** - 自动识别并排除实验报告模板中的公共内容（如标题、实验要求、评分表等），有效避免虚高相似度

3. **抄袭团伙检测算法** - 基于图论算法，自动识别多人互抄团伙，实际应用中成功检测出多组高度相似的报告（最高相似度99.2%）

4. **语义检测** - 使用sentence-transformers进行语义相似度检测，能够识别学生通过同义词替换、句式变换等手段进行的改写抄袭

5. **AI生成检测** - 基于统计特征（句长分布、词汇多样性、语言模式）检测AI生成内容，防范学生使用ChatGPT等工具代写

6. **6维质量评估** - 从技术准确性、内容完整性、分析深度、写作质量、代码质量、原创性6个维度进行全方位评估

### 6.2 教学价值

1. **效率提升** - 批改时间从8小时降至3分钟，效率提升约160倍，大幅减轻教师工作负担

2. **及时反馈** - 学生提交后即可获得详细反馈，不再需要等待数天，提高了学习效率

3. **评估公平** - 标准化评分标准，减少人工评分的主观性，保证评估公平

4. **学习导向** - 详细的个性化反馈和改进建议帮助学生明确学习方向，提高学习质量

5. **数据驱动** - 提供班级整体统计数据（平均分、分数分布、常见问题），为教学改进提供依据

### 6.3 可推广性

1. **学科通用** - 系统设计为模块化架构，适用于各类实验课程的报告评估（不限于STM32）

2. **配置灵活** - 评分标准（Rubric）、技术检查项、相似度阈值等均可通过配置文件自定义

3. **开源可用** - 采用模块化设计，代码结构清晰，易于扩展和二次开发

4. **低门槛使用** - 提供命令行接口和批量处理功能，教师无需编程基础即可使用

### 6.4 教育意义

1. **促进公平公正** - 客观的评估标准确保每位学生得到公平对待

2. **培养诚信意识** - 严格的查重机制培养学生诚信学术态度

3. **提高教学质量** - 及时准确的反馈帮助教师了解学生学习状况，调整教学策略

4. **推动教育信息化** - 将AI技术应用于教学评估，为教育数字化转型提供实践案例
