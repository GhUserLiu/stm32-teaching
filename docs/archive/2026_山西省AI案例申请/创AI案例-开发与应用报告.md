## 一、开发背景

### 1.1 教学痛点

在《汽车微处理器原理与应用》等嵌入式课程教学中，实验报告的批改与评估面临以下突出挑战：

**（1）批改工作量大**
每个实验班级约40名学生，传统人工批改一份完整的实验报告需要10-15分钟，全班批改耗时约8-10小时。教师需要反复阅读相似的代码、检查技术要点、评估分析深度，工作重复性高、效率低。

**（2）查重识别困难**
学生抄袭手段日益多样化：
- 直接复制他人报告文本
- 通过改写、同义词替换规避检测
- 代码逻辑相似但变量名不同
- 小组内互相借鉴形成"团伙抄袭"

传统的人工查重难以全面识别，且容易产生主观偏差。

**（3）反馈不及时**
学生提交报告后，往往需要等待数天才能获得详细反馈。这种延迟降低了学习效率，学生无法及时了解自己的问题并进行改进。

**（4）评估标准不一**
人工评分存在主观性，不同教师或同一教师在不同时间对同一份报告的评分可能存在差异，难以保证评估的公平性和一致性。

**（5）AI代写检测难**
随着ChatGPT等生成式AI工具的普及，学生可能使用AI代写实验报告。如何识别AI生成的内容成为新的挑战。

### 1.2 解决思路可行性分析

针对上述痛点，开发一套智能评估系统的可行性分析如下：

| 痛点 | AI技术解决方案 | 可行性 |
|------|---------------|--------|
| 批改工作量大 | 自动化评分算法 | ✅ 高 - 基于规则的评分系统成熟 |
| 查重识别困难 | 多算法融合相似度计算 | ✅ 高 - 多种NLP算法可供选择 |
| 反馈不及时 | 自动化报告生成 | ✅ 高 - 模板化反馈生成可行 |
| 评估标准不一 | 标准化Rubric评分 | ✅ 高 - 配置化评分标准 |
| AI代写检测 | 统计特征分析 | ✅ 中 - 需持续优化识别算法 |

**技术实现路径**：
- Python生态系统成熟，拥有jieba分词、sentence-transformers语义检测等成熟库
- 无需大量算力，可在普通PC上运行
- 模块化设计，可逐步迭代优化

### 1.3 应用价值

该系统的开发与应用将带来以下价值：
- **效率提升**：批改时间从8小时降至3分钟，效率提升约160倍
- **及时反馈**：学生提交即可获得详细反馈
- **公平评估**：标准化评分标准，减少主观偏差
- **质量监控**：自动识别抄袭和AI代写，维护学术诚信

from difflib import SequenceMatcher

def calculate_sequence_similarity(text1: str, text2: str) -> float:
    """
    基于序列匹配计算文本相似度

    Args:
        text1: 待比较文本1
        text2: 待比较文本2

    Returns:
        相似度百分比 (0-100)
    """
    # 计算序列匹配比率
    ratio = SequenceMatcher(None, text1, text2).ratio()
    return round(ratio * 100, 2)

#### （2）第二阶段：团伙检测与语义分析（2024年7-8月）

**开发目标**：识别多人互抄团伙和改写抄袭

**关键代码实现** - 团伙检测算法：

```python
def detect_plagiarism_circles(similarity_matrix: pd.DataFrame,
                               threshold: float = 65.0) -> List[Dict]:
    """
    基于图论算法检测抄袭团伙

    Args:
        similarity_matrix: 学生相似度矩阵
        threshold: 相似度阈值

    Returns:
        检测到的团伙列表
    """
    circles = []
    students = similarity_matrix.index.tolist()

    # 构建相似度图
    graph = {}
    for i, s1 in enumerate(students):
        for s2 in students[i+1:]:
            if similarity_matrix.at[s1, s2] >= threshold:
                graph.setdefault(s1, []).append(s2)
                graph.setdefault(s2, []).append(s1)

    # 使用连通分量算法查找团伙
    visited = set()
    for student in students:
        if student not in visited:
            circle = []
            queue = [student]
            while queue:
                node = queue.pop(0)
                if node not in visited:
                    visited.add(node)
                    circle.append(node)
                    queue.extend(graph.get(node, []))

            if len(circle) > 1:
                circles.append({
                    'members': circle,
                    'size': len(circle)
                })

    return circles
```

**语义检测集成**：

```python
from sentence_transformers import SentenceTransformer

# 加载预训练模型（中文支持）
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

def calculate_semantic_similarity(text1: str, text2: str) -> float:
    """
    计算语义相似度（识别改写抄袭）

    Args:
        text1: 文本1
        text2: 文本2

    Returns:
        语义相似度 (0-100)
    """
    # 编码文本为向量
    embeddings = model.encode([text1, text2])

    # 计算余弦相似度
    from sklearn.metrics.pairwise import cosine_similarity
    similarity = cosine_similarity([embeddings[0]], [embeddings[1]])[0][0]

    return round(similarity * 100, 2)
```

```python
def generate_feedback_report(student: Dict,
                            rubric_scores: Dict,
                            similarity_warnings: List) -> str:
    """
    生成个性化反馈报告（Markdown格式）

    Args:
        student: 学生信息
        rubric_scores: 评分结果
        similarity_warnings: 抄袭警告

    Returns:
        Markdown格式的反馈报告
    """
    report = f"""# 实验报告评分反馈

**学号**: {student['id']}
**姓名**: {student['name']}
**总分**: {rubric_scores['total']:.1f}/100
**等级**: {rubric_scores['grade']}

## 各项得分详情

"""

    # 各维度得分详情
    for dimension in rubric_scores['dimensions']:
        status = "✅" if dimension['score_percentage'] >= 80 else "⚠️"
        report += f"""### {status} {dimension['name']} ({dimension['score']:.1f}/{dimension['max_points']})
"""

        # 检查项详情
        for criterion in dimension['criteria']:
            icon = "✓" if criterion['passed'] else "✗"
            report += f"- {icon} {criterion['description']}\n"

        report += "\n"

    # 改进建议
    if rubric_scores['suggestions']:
        report += "## 改进建议\n\n"
        for i, suggestion in enumerate(rubric_scores['suggestions'], 1):
            report += f"### 🔴 建议 {i}: {suggestion['title']}\n\n"
            report += f"{suggestion['content']}\n\n"

    # 抄袭警告
    if similarity_warnings:
        report += "## ⚠️ 抄袭警告\n\n"
        for warning in similarity_warnings:
            report += f"- 与{warning['name']}相似度{warning['similarity']}%\n"

    return report
```

**安全防护实现** - ZIP炸弹防护：

```python
import zipfile
import os

def safe_extract(zip_path: str,
                extract_dir: str,
                max_files: int = 1000,
                max_size: int = 100 * 1024 * 1024) -> bool:
    """
    安全解压ZIP文件，防御ZIP炸弹攻击

    Args:
        zip_path: ZIP文件路径
        extract_dir: 解压目录
        max_files: 最大文件数量限制
        max_size: 最大解压大小限制（字节）

    Returns:
        是否解压成功
    """
    try:
        with zipfile.ZipFile(zip_path, 'r') as zf:
            # 检查文件数量
            if len(zf.namelist()) > max_files:
                raise SecurityError(f"文件数量超限: {len(zf.namelist())}")

            # 检查解压后大小
            total_size = sum(zf.info.name.file_size for zf.info in zf.infolist())
            if total_size > max_size:
                raise SecurityError(f"解压大小超限: {total_size}")

            # 检查路径遍历攻击
            for name in zf.namelist():
                if os.path.isabs(name) or ".." in name:
                    raise SecurityError(f"检测到路径遍历: {name}")

            # 安全解压
            zf.extractall(extract_dir)
            return True

    except Exception as e:
        logger.error(f"解压失败: {e}")
        return False
```

## 四、创新与反思

### 4.1 创新点

#### （1）技术创新

**① 多算法融合查重**

集成5种相似度算法（Sequence、Cosine、Jaccard、Levenshtein、Hybrid），可根据不同场景选择最优算法：

```python
# 混合算法配置示例
similarity = (
    text_score * 0.4 +      # 文本相似度
    code_score * 0.4 +      # 代码相似度
    semantic_score * 0.2    # 语义相似度
)
```

创新价值：单一算法难以应对所有抄袭手段，多算法融合显著提升检测准确率。

**② 模板智能过滤**

自动识别并排除实验报告模板中的公共内容（标题、实验要求、评分表等），避免虚高相似度：

```python
# 模板过滤配置
template_patterns = [
    r"实验\d+：.*",           # 实验标题

    r"评分项\s*分值\s*得分"  # 评分表
]
```

创新价值：有效解决"虚高相似度"问题，提高查重准确性。

### 4.2 应用中的问题与挑战

#### （1）语义检测算力需求

**问题**：sentence-transformers模型加载较慢，首次运行需要下载模型文件（约200MB）。

**解决方案**：
- 提供离线模型下载选项
- 添加模型缓存机制
- 提供轻量级模型选项（牺牲部分准确度）

#### （2）AI生成检测准确性

**问题**：基于统计特征的AI生成检测准确率有限，对于高质量的AI生成内容难以识别。

**改进思路**：
- 集成专业AI检测API（如GPTZero）
- 建立学生写作风格基线
- 结合人工抽检复核

#### （3）跨学科推广适配

**问题**：当前评分标准针对STM32实验设计，推广到其他学科需要重新配置。

**改进思路**：
- 开发可视化评分标准编辑器
- 提供多学科评分标准模板库
- 支持自然语言配置评分规则
