# 创AI案例演示视频PPT内容设计

## 视频时长分配（总计8-10分钟）

| 部分 | 时长 | 对应幻灯片 |
|------|------|-----------|
| 案例概述 | 2分钟 | 幻灯片1-3 |
| 实现功能 | 5分钟 | 幻灯片4-6 |
| 应用情况 | 1分钟 | 幻灯片7-8 |
| 结束 | 10秒 | 幻灯片9 |

申报单位：山西工程科技职业大学

申报教师：刘兆骐

> "各位评委好，我今天分享的创AI案例是《基于多算法融合的STM32实验报告智能评估系统》。"

## 幻灯片2：案例概述（约40秒）

**内容：**

```
一、案例概述

应用场景：
• 嵌入式课程实验报告批改与评估
• 适用班级：40-50人标准班级

解决的主要问题：
• 批改工作量大：传统方式需8-10小时
• 查重识别困难：学生抄袭手段多样
• 反馈不及时：学生需等待数天
• 评估标准不一：人工评分存在主观性
• AI代写检测难：ChatGPT普及带来的新挑战
```

**解说词（约40秒）：**
> "本案例应用于嵌入式课程的实验报告评估。在实际教学中，我们面临几个突出痛点：
>
> 第一是批改工作量大，每个实验40多份报告，传统人工批改需要8-10小时；
> 第二是查重识别困难，学生通过直接复制、改写、代码相似等多种手段抄袭；
> 第三是反馈不及时，学生提交后需要等待数天才能获得反馈；
> 第四是评估标准不一，人工评分存在主观性；
> 第五是随着ChatGPT的普及，AI代写检测成为新的挑战。
>
> 针对这些问题，我开发了一套智能评估系统。"

---

## 幻灯片3：系统架构（约50秒）

**内容：**

```
二、系统架构

核心模块：
• 查重检测模块 - 5种算法融合 + 语义检测
• 质量评估模块 - 6维度自动评分
• 反馈生成模块 - 个性化报告生成
• 安全防护模块 - ZIP炸弹防护、数据脱敏

技术栈：
• 开发语言：Python 3.8+
• GUI框架：PyQt6
• 核心算法：jieba分词、sentence-transformers
```

**解说词（约50秒）：**
> "系统采用模块化架构，包含四个核心模块：
>
> 查重检测模块集成了5种相似度算法，包括Sequence、Cosine、Jaccard、Levenshtein和混合算法，还支持语义检测，能够识别改写抄袭；
>
> 质量评估模块从技术准确性、内容完整性、分析深度、写作质量、代码质量、原创性6个维度进行全方位评估；
>
> 反馈生成模块自动生成详细的个性化反馈报告，包括改进建议和代码示例；
>
> 安全防护模块实现了ZIP炸弹防护、路径验证、XXE防护和数据脱敏功能。
>
> 技术上使用Python开发，GUI界面采用PyQt6框架，核心算法使用jieba进行中文分词，sentence-transformers进行语义检测。"

## 幻灯片4：查重检测功能（约1.5分钟）

**内容：**

```
三、实现功能（一）：查重检测

支持5种相似度算法：
• Sequence - 短文本精确匹配
• Cosine - 长文本相似度
• Jaccard - 词语重叠度
• Levenshtein - 编辑距离
• Hybrid - 综合评估（可配置权重）

创新功能：
• 模板智能过滤 - 排除公共内容
• 团伙检测算法 - 识别多人互抄
• 语义检测 - 识别改写抄袭
• AI生成检测 - 防范代写
```

**解说词（约1.5分钟）：**
> "首先介绍查重检测功能。系统支持5种相似度计算算法，可根据不同场景选择：
>
> Sequence算法适合短文本的精确匹配；
> Cosine算法基于TF-IDF计算长文本相似度；
> Jaccard算法计算词语重叠度；
> Levenshtein算法计算编辑距离；
> Hybrid混合算法可配置不同权重，综合评估。
>
> 在此基础上，我们实现了几个创新功能：
>
> 模板智能过滤功能，自动识别并排除实验报告模板中的公共内容，如标题、实验要求等，避免虚高相似度；
>
> 团伙检测算法基于图论连通分量分析，自动识别多人互抄团伙；
>
> 语义检测使用sentence-transformers进行语义相似度计算，能够识别学生通过同义词替换、句式变换等手段进行的改写抄袭；
>
> AI生成检测基于统计特征分析，如句长分布、词汇多样性等，防范学生使用ChatGPT等工具代写。
>
> [演示环节]现在演示查重功能：打开GUI应用，选择实验报告文件夹，点击开始检测，系统自动计算相似度矩阵。"

## 幻灯片5：质量评估与反馈生成（约2分钟）

**内容：**

```
三、实现功能（二）：质量评估与反馈

6维度质量评估：
• 技术准确性（30%） - GPIO配置、中断设置、状态机逻辑
• 内容完整性（25%） - 实验原理、硬件连接、代码实现
• 分析深度（15%） - 问题分析、解决方案讨论
• 写作质量（10%） - 结构、格式、排版
• 代码质量（10%） - 注释、命名规范、模块划分
• 原创性（10%） - 抄袭风险评估

智能反馈生成：
• 自动评分与等级评定（A-F）
• 4-6条优先级排序的改进建议
• 针对性代码示例
• 学习路径推荐

输出格式：Excel / JSON / HTML
```

**解说词（约2分钟）：**
> "接下来介绍质量评估功能。系统从6个维度进行自动评分：
>
> 技术准确性占比30%，检查GPIO配置、中断设置、状态机逻辑等技术要点；
> 内容完整性占比25%，评估实验原理、硬件连接、代码实现是否完整；
> 分析深度占比15%，评价问题分析和解决方案讨论的深度；
> 写作质量、代码质量、原创性各占10%。
>
> 每个维度都有具体的检查项和关键词匹配规则，评分标准通过JSON配置文件可自定义。
>
> 基于评分结果，系统自动生成个性化反馈报告，包括：
>
> 自动评分和A-F等级评定；
> 4到6条按优先级排序的改进建议；
> 针对错误的技术要点提供代码示例；
> 根据薄弱环节推荐学习路径。
>
> 输出格式支持Excel汇总报告、JSON数据格式和HTML可视化报告。
>
> [演示环节]现在演示评分功能：加载评分标准文件，系统自动检测技术要点，计算各维度得分，生成反馈报告。"

## 幻灯片6：GUI应用与安全防护（约1.5分钟）

**内容：**

```
三、实现功能（三）：GUI应用与安全防护

GUI界面功能：
• 仪表盘视图 - 统计概览、快速操作
• 查重视图 - 单文件检测、批量检测
• 多班级视图 - 批量处理、报告整合
• 设置视图 - 评分标准、阈值配置

安全防护措施：
• ZIP炸弹防护 - 文件数量/大小限制
• 路径验证 - 限制目录访问范围
• XXE防护 - 安全XML解析
• 数据脱敏 - 学生信息匿名化
```

**解说词（约1.5分钟）：**
> "系统提供友好的图形用户界面，包含四个主要视图：
>
> 仪表盘视图显示统计概览和最近使用的项目，支持快速操作；
> 查重视图支持单文件检测和批量检测，可查看详细结果；
> 多班级视图支持批量处理多个班级的报告，并可整合输出；
> 设置视图允许教师自定义评分标准和相似度阈值。
>
> 在安全防护方面，系统实现了多项措施：
>
> ZIP炸弹防护限制解压文件数量和大小，防止拒绝服务攻击；
> 路径验证限制文件访问范围，防止路径遍历攻击；
> XXE防护使用安全的XML解析器，防御外部实体注入；
> 数据脱敏功能支持学生信息匿名化，保护隐私。
>
> [演示环节]现在展示GUI应用的主要功能。"

## 录制注意事项

1. **录制方式**：PPT + 录屏 + 解说
2. **画面要求**：
   - 不出镜，使用PPT画面
   - 可包含GUI操作演示录屏
   - 片头片尾使用模板的首页和尾页
3. **技术规格**：
   - 格式：MP4
   - 比例：16:9
   - 分辨率：1920×1080
   - 帧率：25帧/秒
   - 码率：≥8Mbps
4. **内容要求**：
   - 标记AI生成内容
   - 保护学生隐私，不出现正面画面
