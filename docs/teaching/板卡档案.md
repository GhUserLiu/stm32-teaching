# 板卡档案（本实训硬件唯一基准记录）

> 建档 2026-10-29。**规则：一切接线/引脚/代码以本文档为准；本文档以"实物 + 官方资料双轨核对"更新。改动任何引脚须同步本档。**

## 1. 实际板卡（已实物确认）

| 项 | 内容 |
|---|---|
| 型号 | **野火小智 STM32F103C8T6 核心板【初款】**（方形，无板载 USB 转串口） |
| MCU | STM32F103C8T6，LQFP48，72MHz，64K Flash / 20K RAM |
| **封装限制** | **C 口仅引出 PC13/PC14/PC15——PC0~PC12 物理不存在**（PC14/15 被 32.768K 晶振占用，实际可用 C 口只有 PC13） |
| 排针 | 四排（两对，每对=公排+母排）；同对内公母为同一信号 1:1 并联（按官方引脚总数 33 推定，首测可蜂鸣档抽验） |
| 串口 | 无板载 CH340——用套件外接 **CH340 TTL 线**（TX/RX 交叉接 PA10/PA9） |
| 烧录 | DAP(SWD) 四线主用；BOOT0 跳线 + FlyMcu 串口 ISP 备用 |

**与"双 USB 款"的区别**（资料里大量文件是双 USB 款的，勿混）：
双 USB 款 = 板载 CH340 串口 + ISP 一键下载电路（Type-C 直连可下载）。**引出 IO 定义两版相同**（33 个一致），差异只在板载串口电路。

## 3. 引脚分配总表（本档基准 · 全部经"存在性"核验）

| 模块 | 引脚 | 来源/备注 |
|---|---|---|
| KEY1 | PA0 | 官方表【双款一致】；低电平按下 |
| KEY2（备用） | PC13 | 同上 |
| 板载 RGB | R=PA1 G=PA2 B=PA3 | 同上；**低电平点亮**（官方例程 [10] 初始化写高=灭证实） |
| 光敏 AO | PA4 (ADC1_IN4) | 对齐官方例程 [21-2] |
| 热敏 AO | PA6 (ADC1_IN6) | 对齐官方例程 [21-2] |
| MQ-135 备用 | PA5 (ADC1_IN5) | 官方 Ir_AO 位，互斥使用 |
| TB6612 | AIN1=PB0 AIN2=PB1 PWMA=PA8(TIM1_CH1) STBY→3.3V | 本框架分配（官方 [26] 用 PA4/5/7 与光敏冲突） |
| OLED | SCL=PB6 SDA=PB7（软件 I2C） | 与官方 [31] 同脚 |
| **蜂鸣器** | **PB5** | **2026-10-29 修正**：原 PC2 不存在（C8T6 封装） |
| DHT11 | DATA（裸件丝印 **IO**）=PB12；NC 脚悬空；裸件不稳加 4.7K~10K 上拉 | 对齐官方 [29] |
| 串口 | PA9(TX)/PA10(RX) 115200 | 外接 CH340 线交叉 |
| SWD | PA13/PA14 | DAP |

**空闲可扩展**：PA7、PA11、PA12、PA15、PB2~PB4（JTAG 态需禁用）、PB8~PB11、PB13~PB15、PC13。

## 4. 首次上电实测清单（f1-selftest 首验时核对——这些是"双款一致"的待证假设）

- [ ] T1：红灯（PA1）1Hz 闪 → 证实 RGB 引脚与低亮极性
- [ ] T3：按板载 KEY1（PA0）有效 → 证实 KEY1 引脚/电平
- [ ] 蜂鸣器（PB5）间歇鸣 → 本次修正脚的实测确认
- [ ] 公母排针抽验：万用表蜂鸣档量 2~3 个同编号公母脚直通

> 历史教训存档：①早期按双 USB 款假设 Type-C 可下载（初款实物无 USB 口）②蜂鸣器曾排 PC2（C8T6 无此脚）③DHT11 裸件丝印为 IO 非 DATA。**三者均为"资料型号 ≠ 实物"或"封装想当然"所致，引以为戒。**
