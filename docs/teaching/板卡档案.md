# 板卡档案（本实训硬件唯一基准记录）

> 建档 2026-10-29。**规则一**：一切接线/引脚/代码以本文档为准；本文档以"实物 + 官方资料双轨核对"更新；改动任何引脚须同步本档。
> **规则二（型号规范）**：任何文档/评分标准/工程/课件提及板卡，**必须写全型号（厂商+型号+版款）**，禁止只写"F103 板/F407 板"——同型号不同板卡的引脚布局可能完全不同。新增板卡先登台账再使用。
> **规则三（2026-10-29 定）**：**板卡判定以"芯片丝印 + 板面 USB 口 + 排针丝印"为准；背面 PCB 料号（EBF xxx）不同产品线会撞型，不得单独作为判型依据。**

## 1. 实际板卡（2026-10-29 实物三验定案：芯片丝印 F103 + 双 USB 口 + 长方形板）

| 项 | 内容 |
|---|---|
| 型号 | **野火小智 STM32F103C8T6 核心板【双 USB 款】**（长方形，双 USB 口） |
| MCU | STM32F103C8T6，LQFP48，72MHz，64K Flash / 20K RAM（丝印证实；批号 99GIP 非标准 ST 格式，疑兼容片，功能按 F103 不受影响） |
| **封装限制** | **C 口仅引出 PC13/PC14/PC15——PC0~PC12 物理不存在**（PC14/15 被 32.768K 晶振占用，实际可用 C 口只有 PC13） |
| USB ① | Type-C：**板载 CH340 USB 转串口**——PA9/PA10 **经跳线帽**连接（串口不通先查帽）；支持 ISP 一键下载（FlyMcu 勾 RTS/DTR） |
| USB ② | USB Device 口（USB 实验用） |
| 排针 | 公母双排；同对内公母为同一信号 1:1 并联（推定，首电可蜂鸣档抽验） |
| 烧录 | DAP(SWD) 四线主用；Type-C 串口一键下载备用 |

## 3. 引脚分配总表（本档基准 · 全部经"存在性"核验）

| 模块 | 引脚 | 来源/备注 |
|---|---|---|
| KEY1 | PA0 | 官方表【双款一致】；低电平按下 |
| KEY2（备用） | PC13 | 同上 |
| 板载 RGB | R=PA1 G=PA2 B=PA3 | 同上；**低电平点亮**（官方例程 [10] 初始化写高=灭证实） |
| 光敏 AO | PA4 (ADC1_IN4) | 对齐官方例程 [21-2] |
| 热敏 AO | PA6 (ADC1_IN6) | 对齐官方例程 [21-2] |
| MQ-135 备用 | PA5 (ADC1_IN5) | 官方 Ir_AO 位，互斥使用 |
| TB6612 | AIN1=PB0 AIN2=PB1 PWMA=PA8(TIM1_CH1) STBY→3.3V | 本框架分配（官方 [26] 用 PA4/5/7 与光敏冲突） |
| OLED | SCL=PB6 SDA=PB7（软件 I2C） | 与官方 [31] 同脚 |
| **蜂鸣器** | **PB5** | **2026-10-29 修正**：原 PC2 不存在（C8T6 封装） |
| DHT11 | DATA（裸件丝印 **IO**）=PB12；NC 脚悬空；裸件不稳加 4.7K~10K 上拉 | 对齐官方 [29] |
| 串口 | PA9(TX)/PA10(RX) 115200 | **板载 CH340（Type-C 直连，查 PA9/PA10 跳线帽）**；套件外接 CH340 线作备用 |
| SWD | PA13/PA14 | DAP |

**空闲可扩展**：PA7、PA11、PA12、PA15、PB2~PB4（JTAG 态需禁用）、PB8~PB11、PB13~PB15、PC13。

## 4. 首次上电实测清单（f1-selftest 首验时核对）

- [ ] T1：红灯（PA1）1Hz 闪 → 证实 RGB 引脚与低亮极性
- [ ] T3：按板载 KEY1（PA0）有效 → 证实 KEY1 引脚/电平
- [ ] 蜂鸣器（PB5）间歇鸣 → PB5 修正脚的实测确认
- [ ] Type-C 插电脑出 COM 口、跳线帽在位 → 板载串口证实
- [ ] 公母排针抽验：万用表蜂鸣档量 2~3 个同编号公母脚直通

> 历史教训存档：①"方形无 USB → 初款"误判（实际双 USB 款；早期观察对象存疑）②蜂鸣器曾排 PC2（C8T6 封装无此脚）③DHT11 裸件丝印为 IO 非 DATA ④背面 PCB 料号 EBF C48 被误搜成 PY32 板（料号撞型，芯片丝印才是铁证）。**共同根因：以局部特征代替完整核验——判板必须"芯片丝印 + USB 口 + 排针丝印"三验。**
