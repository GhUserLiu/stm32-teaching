# 单片机课程软件 · 数据结构设计（2026-10 定稿）

> 单一真源原则：**每类数据只有一个维护点**，其余皆为只读回退或生成产物。
> 年度演进 = 只改数据文件，不改程序。

## 1. 分层总图

```
data/
├── semesters/                    ★ 学期模板（唯一维护点）
│   ├── 2026-春季/                ├─ experiments.yaml   实验清单（ID/名称/专业/类型/rubric指向）
│   │                             └─ rubrics/*.json     该学期评分标准
│   └── 2026-秋季/                └─ 同上
├── rubrics/                      ○ 全局评分标准（无学期时的回退层，新标准直接进学期包）
├── config/teaching/
│   ├── config.yaml               ○ 运行参数（阈值/权重/输出）+【冻结】experiments/classes
│   ├── .student_ui_state.json    ~ 学生端记忆（学期/专业/类型/上次实验，自动生成）
│   └── .teacher_ui_state.json    ~ 教师端记忆（同上，自动生成）
└── teaching/                     ~ 业务数据（提交/批阅/查重产物，按 学期/班级/实验 落盘，含PII勿外传）
config/base.yaml                  ○ 统一配置层（schemas 校验，教师端打包随包）
```
★=维护点 ○=回退/参数 ~=运行时生成

## 2. 实验清单：四级选择模型

```
学期(目录名) → 专业(majors声明) → 课程类型(type声明) → 实验(ID键)
```

- **学期命名**：`<年份>-春季|秋季`（年份在前保证字典序=时间序；新季节类型需同步 list_semesters 排序约定）
- **专业**：清单条目 `majors: [汽服|新能源|智能网联汽车|…]`，不写=全专业通用；下拉项由各学期 majors 并集自动生成（`list_majors`）
- **课程类型**：条目 `type: 理实一体课|整周实训`，不写=不限；下拉项由并集生成（`list_course_types`）——**两端 UI 均从模板读，无硬编码**
- **实验 ID 编码**：`<学期码>-<类型码>-<专业码>-<序号>`，如 `2026F-PT-NEV-02`；`00`=总项目/期末项，`01..`=分任务；GEN=跨专业共享
- **rubric 指向**：条目 `rubric: rubrics/xxx.json`（相对学期包）；解析顺序：学期包同名 `<ID>.json` → yaml rubric 字段 → 全局 `data/rubrics/<ID>.json` → rubric.json（告警）

## 3. 加载链（所有读取方一致）

| 读取 | 链路 |
|---|---|
| 实验列表 | 学期模板 → config.yaml(冻结) → 内置清单 |
| 评分标准 | 学期包（同名/rubric字段）→ 全局 rubrics |
| 专业/类型下拉 | 学期模板并集 → 空则教师端内置两常项 |

学生端与教师端共用 `path_helper.load_experiments / list_majors / list_course_types`——**同源同序**，两边看到的实验集合完全一致。

## 4. 打包差异（同一模板，两种切面）

| | 学生端包 | 教师端包 |
|---|---|---|
| 学期模板 | ✅ 全带 | ✅ 全带 |
| rubric | **脱敏**（剔 reference_answers 答案文本/common_issues，保留题号） | 完整 |
| config.yaml | **剥离 experiments/classes 段** | 同左 |
| 授权 | 网络时间+防回拨+到期（构建烧入） | 无 |
| 数据树 | 只读（bundle 内） | 便携式（首启拷到 exe 旁，成绩可写、升级保留） |

## 5. 演进操作卡

- **新学期**：复制上学期文件夹改名 → 重编实验 ID（学期码+1）→ 改 experiments.yaml → 需要新标准的加 rubric
- **新专业**：清单条目 majors 加名 + 建对应实验；下拉自动出现
- **新课程类型**：条目 type 用新词即可，下拉自动出现（教师端无模板时回退内置两常项）
- **改评分权重**：只改学期包 rubric，两端下次启动生效
- **升级软件**：换 exe 文件夹；教师端 `data/`（成绩）原地保留
