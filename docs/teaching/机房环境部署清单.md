## 编码转换小工具

`codeTransmit.exe`（53MB，绿色单文件）：学生报告从 GBK 转 UTF-8 时用。**非必装**，遇到中文乱码才需要，放共享盘即可。

## 教师机额外项

- 仓库 + conda 环境 `stm32_teaching`（双击 `启动教学管理系统.bat`）
- 教学管理批阅依赖同 ⑨（make/gcc），否则编译项全班跳过

## 部署后总验证（抽 1 台机 5 分钟）

1. 插 CH340 线 → fireTools 115200 能收到 `f1-selftest` 板子输出
2. Keil 打开例程 [10] → 编译 0 Error
3. DAP 插上 → Keil Download 成功（或 pyOCD list 可见）
4. MCU_SelfCheck 双击正常 → 学期/专业/类型/实验四级下拉正常
5. 提交一个 f1 工程自检 → "编译通过"（若装了 ⑨）
