① 显示层 · 串口 printf 调试输出（UART）

次序：周1（二）1~2　|　产出：实训日志2 + 数据记录表　| 板卡：野火小智 STM32F103C8T6（初款）　|　参考例程：官方 [19-2]

一句话讲清

串口是嵌入式开发的第一调试手段——程序跑在板子上，你"看不见"它，printf 就是把变量实时"说"给电脑听。

接线（3 根，交叉！）

CH340 USB 转 TTL 线核心板
RXDPA9（板 TX）
TXDPA10（板 RX）
GNDGND
最常见错误：TX/RX 没交叉。记法：线的 TX 接板的 RX。USB 端插电脑，设备管理器看到 USB-SERIAL CH340 (COMx) 即驱动 OK。

三步配置（CubeMX）

  1. USART1 → Mode: Asynchronous（异步）
  2. 参数：Baud 115200 / 8-N-1
  3. 生成代码，HAL 已备好 HAL_UART_Transmit()

printf 重定向（核心一段）

/* 让 printf 走 USART1 —— 加到 main.c 用户区 */
#include <stdio.h>

int fputc(int ch, FILE *f)          /* Keil 用这个 */
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, 0xFFFF);
    return ch;
}
/* GCC 工程则改写 int _write(int fd,char*ptr,int len){...} 同理 */
printf("T=%.1fC\r\n", temp);       /* 用法与 C 语言课完全相同 */

注意 \r\n 换行；工程选项里勾选 MicroLIB（Keil）可减小 printf 体积。

当堂任务（约 80 min）

  1. 每 1s 打印一行：[组号] sys run: xx s（HAL_GetTick() 计秒）
  2. 打印一个变化的变量（如自增计数、ADC 随手读一个值）
  3. 做数据记录表：同一条语句，改波特率 9600/115200 各截一张串口助手截图，记录现象（乱码/正常）与原因

三个坑

现象原因
完全无输出TX/RX 没交叉 / GND 没接 / COM 口选错
乱码波特率不匹配（双方必须同为 115200）
输出卡顿丢字用了阻塞发送超时太短，或在中断里 printf

官方例程对照（照着做就对了）

配套资料里的工程：《[19-2] 串口发送之发送字符串与printf函数》（开课前先读资料包《[0]例程使用前必读说明.pdf》）。官方代码与上面讲的完全一致：

/* 官方 main.c 用户区 —— printf 重定向（原文） */
int fputc(int ch, FILE *f)
{
    HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
    return ch;
}

/* 官方主循环（原文，演示用 HAL_Delay；最终项目里要改成 HAL_GetTick 非阻塞） */
while (1) {
    printf("你好，欢迎使用野火小智！\r\n");
    HAL_Delay(1000);
}
文件看什么
Core/Src/usart.cMSP 里官方自动配好 PA9=TX / PA10=RX（与接线一致，不用改）
Core/Src/main.cfputc 写在 USER CODE BEGIN 4 区——CubeMX 重新生成代码不会被覆盖

printf 深入：何时用、何时别用（课程组重点要求）

场景该用吗怎么做
看传感器读数是否正常✅ 最该用定时打印 raw/换算值，对照预期
程序卡死，不知道跑到哪✅ 打点定位在怀疑位置插 printf("here A\r\n")，卡在哪一桩就清楚了
状态机切换跟踪✅ 进阶必用printf("mode:%d->%d\r\n", old, new)，切换异常一目了然
启动自检/错误上报✅ 工程惯例上电打印版本号；初始化失败打印原因
中断服务函数里❌ 别用printf 是阻塞发送，会拖死中断；改置标志，主循环再打印
微秒级时序段（DHT11 读数中）❌ 别用一打印时序就乱，读数必失败；先存数组，读完再打印
主循环每圈都打⚠ 慎用主循环 <1ms 时 printf 拖慢节奏；用计数器降到 10 次/秒

printf 格式速查（够用版）

printf("%d\r\n",  temp);      // 整数
printf("%u\r\n",  tick);      // 无符号（HAL_GetTick 返回值用 %lu 更稳）
printf("%.1f\r\n", voltage);  // 小数保留 1 位（浮点打印需勾 MicroLIB/完整库）
printf("%s count=%d\r\n", "DHT11", n);   // 混合
printf("0x%02X\r\n", reg);    // 十六进制看寄存器（调试 I2C/OLED 神器）
工程习惯：定义宏开关 #define DBG 1，发布版改 0 一键静音—— #if DBG  printf(...)  #endif

串口工具使用步骤（人手一份）

  1. 找 COM 号：CH340 线插电脑 → 右键开始菜单 → 设备管理器 → 「端口(COM 和 LPT)」→ 记下 USB-SERIAL CH340 (COM3) 的 COM 号（拔插一次看谁消失，最不会认错）
  2. 打开串口工具——野火串口助手 fireTools（配套资料《4-软件工具\串口调试工具与串口下载\串口调试工具\野火串口助手》，解压即用； 其他工具如 SSCOM/XCOM 操作完全相同），按 四要素设置： 波特率 115200、数据位 8、停止位 1、校验 无，流控不勾
  3. 选对 COMx → 点「打开串口」→ 按板子复位键，应立刻收到一串输出
  4. 常用三键：「清空」（重新观察）、「暂停」（读屏）、「保存/记录」—— 做数据记录表就靠保存：先存成 .txt/.csv，再整理进实验报告
  5. 收不到？按顺序查：COM 号选错 → TX/RX 没交叉 → 波特率不一致 → 驱动没装好
