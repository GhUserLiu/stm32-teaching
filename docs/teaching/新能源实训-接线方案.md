# 智能座舱温控系统 · 接线方案（学生施工版·官方例程对齐）

> 目标板：野火小智 STM32F103C8T6 核心板（初款，正方形，**无板载 USB**）
> 引脚依据：官方引脚分配表 + 官方例程（手谕匣已存）
> 代码引脚唯一真源：`src/common-f1/inc/board_f1.h`
> 原则：**最大化利用板载资源，面包板完全不用**；一次接完 → 烧 `f1-selftest` → 逐项读结果。

## 1. 板载资源（无需接线，代码已配好）

| 板载硬件 | 引脚 | 说明 |
|---|---|---|
| RGB LED | **R=PA1 G=PA2 B=PA3** | 低电平点亮（官方例程证实）；默认用红 PA1 |
| 按键 KEY1 | **PA0** | 按下=低电平，内部上拉 |
| 按键 KEY2 | **PC13** | 备用（进阶：手动/自动双键） |
| SWD 调试口 | PA13/PA14 | DAP 四线烧录 |
| 8MHz / 32.768K 晶振 | PD0/PD1、PC14/PC15 | 已占用不可用 |

> 初款核心板**没有板载 USB 转串口**——串口通信与 ISP 下载均用套件自带的
> **野火 USB 转 TTL 线（CH340）**，见 §2 第 7 组。

## 2. 外接模块（杜邦线直插，共 7 组）

| # | 模块 | 接法 | 线数 |
|---|------|------------------|------|
| 1 | OLED 0.96" I2C | VCC→3.3V，GND→GND，SCL→**PB6**，SDA→**PB7** | 4 |
| 2 | DHT11 | VCC→3.3V，GND→GND，DATA→**PB12** | 3 |
| 3 | 有源蜂鸣器 | VCC→3.3V，GND→GND，I/O→**PB5** | 3 |
| 4 | 光敏模块 | VCC→3.3V，GND→GND，**AO→PA4**（不是 DO！） | 3 |
| 5 | 热敏模块 | VCC→3.3V，GND→GND，**AO→PA6**（不是 DO！） | 3 |
| 6 | TB6612FNG + 电机风扇 | VCC→3.3V，**STBY→3.3V**，GND→GND，AIN1→**PB0**，AIN2→**PB1**，PWMA→**PA8**；VM→**扩展板电源 5V**（GND 共地）；**有刷小马达两极→AO1/AO2**（**风扇叶提前装到马达轴上**，无正负之分） | 8+2 |
| 7 | **USB 转 TTL（CH340）** | **线的 RXD→PA9、TXD→PA10、GND→GND**（线的 VCC 不接或接 5V 供电脚）；USB 端连电脑 | 3 |

**LED 用板载 RGB、按键用板载 KEY1 —— 五色灯珠、按键、面包板本次全部不用。**

> **烟雾排风联动（备用件 MQ-135，选用）**：AO→**PA5**、VCC/GND 同其他模块。
> 接好后无需改线——`f1-cabin-thermal` 已内置：烟雾超限 → **电机风扇全速排风 + 2Hz 快鸣报警**，
> 回落自动解除（滞回阈值在 main.c 顶部 `SMOKE_TH_ON/OFF`，按实测调）。
> **未接 MQ-135 的组**须把 main.c 的 `SMOKE_ENABLE` 改 0（否则悬空误报）。
> MQ-135 通电需预热约 60s（固件已做预热屏蔽）。

> 串口交叉记法：**线的 TX 接板的 RX，线的 RX 接板的 TX**（TX↔RX 交叉）。

## 3. 烧录与供电

> **软件工具全清单见《[机房环境部署清单](机房环境部署清单.md)》**（Keil5.36/AC5/F1芯片包/CubeMX/CH341驱动/fireTools/FlyMcu/arm-gcc 全在配套《4-软件工具》）

- **DAP 调试器**（4 根）：3.3V→3.3V，GND→GND，SWDIO→SWDIO，SWCLK→SWCLK；USB 连电脑——**烧录首选**
- 备选（无 DAP 时）：CH340 线串口 ISP——BOOT0 跳 3.3V → 复位 → FlyMcu 下载（**不勾** RTS/DTR）→ 完成后 BOOT0 跳回 GND
- 供电：扩展板电源（或 DAP/TTL 线的电源脚）给核心板 5V/3.3V
- 上电顺序：核对检查单 → 核心板 → 扩展板电源（电机）最后开

## 4. 一次性接线 + 验收流程（推荐）

1. 按 §2 接完 7 组线 + DAP 四线，核对 §5 检查单
2. 烧 `f1-selftest`，开串口助手 115200（选 CH340 对应 COM 口）
3. 等 10s，看 OLED/串口：
   - LED 行 OK = 板载红灯 1Hz 闪
   - KEY 行 = **按一下板载 KEY1** 变 OK（蜂鸣器静音）
   - BUZZ 行 = 松开按键后 0.5s 间歇鸣叫
   - DHT11 行 = 等 2s 报温湿度
   - ADC 行 = 遮光/照光看 LIGHT 变化、捏热敏看 NTC_T 上升
   - FAN 行 = 风扇 5s 一档循环调速
4. 六项全 OK → OLED 右上角 **PASS**，串口 `ALL PASS`
5. 某项 ERR → 对照 §6 只查该模块的 3~4 根线

## 5. 上电前检查单（逐项打勾）

- [ ] CH340 线 TX/RX **交叉**接到 PA10/PA9（最常见错误：没交叉）
- [ ] TB6612：STBY=3.3V、VCC=3.3V、VM=扩展板电源 5V
- [ ] 扩展板电源 GND 与核心板 GND 已共地
- [ ] 光敏/热敏接 **AO** 模拟输出脚（DO 是数字阈值输出，接了恒 0/4095）
- [ ] DHT11 用 3.3V
- [ ] 马达不接核心板任何电源引脚
- [ ] 杜邦线逐根轻拉确认无松动

## 6. 故障速查

| 现象 | 先查 |
|------|------|
| 串口无输出/乱码 | TX/RX 是否交叉；波特率 115200；CH340 驱动（设备管理器看 COM 号） |
| 板载灯不闪 | LED_ACTIVE_LOW 极性宏（board_f1.h，共阳/共阴对调） |
| KEY 无反应 | 按的是板载 KEY1（PA0），不是 KEY2 |
| OLED 全黑 | SCL/SDA 接反；地址 0x3C；换模块 |
| DHT11 ERR | PB12、3.3V；两次读取间隔 ≥1s |
| ADC 恒 0/4095 | 接了 DO；PA4/PA6 松动 |
| 风扇不转 | STBY 没拉高；VM 没电；AIN/PWM 三根线 |
| 风扇转但失控 | 独立电源未共地 |
| DAP 连不上 | SWD 四线；核心板已上电；换 USB 口/线 |

## 7. 接线对照图（文字版）

```
 3.3V ──┬── OLED VCC ── DHT11 VCC ── 蜂鸣器 VCC ── 光敏 VCC ── 热敏 VCC
        └── TB6612 VCC、STBY
 核心板 PA0 ←── 板载 KEY1        PA1 ── 板载 LED_R（例程默认灯）
        PB5 ──→ 蜂鸣器 I/O       PA2/PA3 ── 板载 LED_G/LED_B（进阶）
        PB12 ←─ DHT11 DATA       PB6 ── OLED SCL   PB7 ── OLED SDA
        PA4 ←── 光敏 AO          PA6 ←── 热敏 AO
        PB0 ── TB6612 AIN1       PB1 ── TB6612 AIN2
        PA8 ──→ TB6612 PWMA      PA9(TX) ←── CH340线RXD
                                 PA10(RX) ←─ CH340线TXD   （TX/RX 交叉）
 GND ───┴── 所有模块 GND ── TB6612 GND ── 扩展板电源 GND ── CH340线GND ── DAP GND
 扩展板 5V(+) ── TB6612 VM ── AO1/AO2 ── 小马达（轴上装风扇叶，转向反了交换两线）
```
