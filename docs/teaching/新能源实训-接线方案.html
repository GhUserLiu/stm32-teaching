智能座舱温控系统 · 接线方案

目标板：野火小智 STM32F103C8T6 核心板（初款，正方形，无板载 USB）　 依据：官方引脚分配表 + 官方例程　 代码引脚真源：src/common-f1/inc/board_f1.h
原则：最大化利用板载资源，面包板完全不用；一次接完 → 烧 f1-selftest → 逐项读结果

1. 板载资源（无需接线，代码已配好）

板载硬件引脚说明
RGB LEDR=PA1 G=PA2 B=PA3低电平点亮（官方例程证实）；默认用红 PA1
按键 KEY1PA0按下=低电平，内部上拉
按键 KEY2PC13备用
SWD 调试口PA13/PA14DAP 四线烧录
晶振PD0/PD1、PC14/PC158MHz / 32.768K，已占用不可用
初款核心板没有板载 USB 转串口——串口通信与 ISP 下载均用套件自带的 野火 USB 转 TTL 线（CH340），见 §2 第 7 组。

2. 外接模块（杜邦线直插，共 7 组）

#模块接法线数
1OLED 0.96" I2CVCC→3.3V，GND→GND，SCL→PB6，SDA→PB74
2DHT11VCC→3.3V，GND→GND，DATA→PB123
3有源蜂鸣器VCC→3.3V，GND→GND，I/O→PB53
4光敏模块VCC→3.3V，GND→GND，AO→PA4（不是 DO！）3
5热敏模块VCC→3.3V，GND→GND，AO→PA6（不是 DO！）3
6TB6612FNG + 电机风扇VCC→3.3V，STBY→3.3V，GND→GND，AIN1→PB0，AIN2→PB1，PWMA→PA8；VM→扩展板电源 5V（GND 共地）；有刷小马达两极→AO1/AO2（风扇叶提前装到马达轴上，无正负之分）8+2
7USB 转 TTL（CH340）线的 RXD→PA9、TXD→PA10、GND→GND（线的 VCC 不接或接 5V 供电脚）；USB 端连电脑3
LED 用板载 RGB、按键用板载 KEY1 —— 五色灯珠、按键、面包板本次全部不用。
串口交叉记法：线的 TX 接板的 RX，线的 RX 接板的 TX（TX↔RX 交叉）。

3. 烧录与供电

  • DAP 调试器（4 根）：3.3V→3.3V，GND→GND，SWDIO→SWDIO，SWCLK→SWCLK；USB 连电脑——烧录首选
  • 备选（无 DAP 时）：CH340 线串口 ISP——BOOT0 跳 3.3V → 复位 → FlyMcu 下载（不勾 RTS/DTR）→ 完成后 BOOT0 跳回 GND
  • 供电：扩展板电源（或 DAP/TTL 线的电源脚）给核心板 5V/3.3V
  • 上电顺序：核对检查单 → 核心板 → 扩展板电源（电机）最后开

4. 一次性接线 + 验收流程（推荐）

  1. 按 §2 接完 7 组线 + DAP 四线，核对 §5 检查单
  2. 烧 f1-selftest，开串口助手 115200（选 CH340 对应 COM 口）
  3. 等 10s，看 OLED/串口：
    • LED 行 OK = 板载红灯 1Hz 闪
    • KEY 行 = 按一下板载 KEY1 变 OK（蜂鸣器静音）
    • BUZZ 行 = 松开按键后 0.5s 间歇鸣叫
    • DHT11 行 = 等 2s 报温湿度
    • ADC 行 = 遮光/照光看 LIGHT 变化、捏热敏看 NTC_T 上升
    • FAN 行 = 风扇 5s 一档循环调速
  4. 六项全 OK → OLED 右上角 PASS，串口 ALL PASS
  5. 某项 ERR → 对照 §6 只查该模块的 3~4 根线

5. 上电前检查单（逐项打勾）

  • ☐ CH340 线 TX/RX 交叉接到 PA10/PA9（最常见错误：没交叉）
  • ☐ TB6612：STBY=3.3V、VCC=3.3V、VM=扩展板电源 5V
  • ☐ 扩展板电源 GND 与核心板 GND 已共地
  • ☐ 光敏/热敏接 AO 模拟输出脚（DO 是数字阈值输出，接了恒 0/4095）
  • ☐ DHT11 用 3.3V
  • ☐ 马达不接核心板任何电源引脚
  • ☐ 杜邦线逐根轻拉确认无松动

6. 故障速查

现象先查
串口无输出/乱码TX/RX 是否交叉；波特率 115200；CH340 驱动（设备管理器看 COM 号）
板载灯不闪LED_ACTIVE_LOW 极性宏（board_f1.h，共阳/共阴对调）
KEY 无反应按的是板载 KEY1（PA0），不是 KEY2
OLED 全黑SCL/SDA 接反；地址 0x3C；换模块
DHT11 ERRPB12、3.3V；两次读取间隔 ≥1s
ADC 恒 0/4095接了 DO；PA4/PA6 松动
风扇不转STBY 没拉高；VM 没电；AIN/PWM 三根线
风扇转但失控独立电源未共地
DAP 连不上SWD 四线；核心板已上电；换 USB 口/线
