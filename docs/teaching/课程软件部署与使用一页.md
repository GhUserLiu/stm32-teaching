# 单片机课程软件 · 部署与使用一页（发给课程组同事）

## 包内容

| 包 | 给谁 | 是什么 |
|---|---|---|
| `教师端-单片机课程教学管理系统.zip`（源码包） | 授课教师（自己电脑） | 批阅/查重/成绩管理 |
| `学生端-MCU_SelfCheck.zip`（绿色软件） | 学生（教师转发到班群） | 作业自检与自评，解压双击即用 |

## 教师端部署（解压即用，约 1 分钟）

1. 解压 `教师端-MCU_Teaching.zip` 到**非系统盘**可写目录（如 `D:\单片机教学系统\`）
2. 双击 **`MCU_Teaching.exe`**——首启自动在 exe 旁生成 `config/`、`data/` 工作目录
   - 学期模板/评分标准在 `data\semesters\`，**改这里即可定制**，不动程序
   - 学生成绩数据落在 `data\teaching\`，含隐私，勿外传；升级 = 用新包替换 exe 文件夹里的 `_internal`，`data\` 不动即保留全部成绩
3. （编译分必备）装 arm-none-eabi-gcc + make 并加 PATH，否则批阅时编译项全班跳过

> 开发/维护者（改代码）仍走源码 + conda 环境；授课教师用 exe 即可。

## 教师端日常使用（三步）

1. **数据源页**：选学期/课程类型（会记住）→ 添加班级压缩包（可多选）
2. **批阅与查重页**：点 **🚀 一键：批阅→查重** → 出分数与相似对
3. **结果表双击学生行** → 现场调教师实测分（出勤/子系统/答辩/进阶），改完自动重算总分
   - 「查看班级报告」看分布排名；「导出个人报告」批量导出

菜单 帮助→功能介绍 有同样内容的速览。

## 学生端要点（告诉学生）

- 解压任意目录，双击 `MCU_SelfCheck.exe`（有效期至 **2026-11-15**，联网校时）
- 选：学期 → 专业 → 课程类型 → 实验（会记住上次选择）
- 报告 `.docx` + 源码 `.zip`（须含 Makefile + common-f1，例程工程作底座）
- 点「开始检测」→ 自动跳反馈页看逐项得分与改进建议；改完可无限次重测
- 最终交付用「📦 打包提交」生成规范压缩包（学习通上传）

## 数据与维护

- 每学期一套标准在 `data/semesters/<学期>/`（experiments.yaml + rubrics/）
- **新学期 = 复制上学期文件夹改名 → 按头注释规则重编实验 ID → 改 yaml**，程序零改动
- 学生成绩数据落 `data/teaching/<学期>/<班级>/<实验>/`，含 PII，勿外传
