# 新能源汽车工程实训（电子控制方向）· 套件接线与验收手册

> 适用：野火小智 STM32F103C8T6 基础功能 21 件套（6 套；核心板为**双 USB 款**）
> 工程位置：`src/common-f1/`（框架）+ `src/projects/f1-*`（自检固件与例程）
> 编译：`make`（arm-none-eabi-gcc）；无 make 时用 `powershell -File scripts/build_f1.ps1 <项目名>`

## 1. 统一引脚分配（board_f1.h）

| 模块 | 引脚 | 说明 |
|------|------|------|
| 板载 RGB LED | R=PA1 G=PA2 B=PA3 | 例程默认用红（PA1）；低电平点亮 |
| 板载按键 KEY1 | PA0 | 按下=低电平（KEY2=PC13 备用） |
| 有源蜂鸣器 | PB5 | 高电平响 |
| DHT11 | PB12 | DATA，VCC=3.3V |
| OLED（4Pin I2C） | SCL=PB6，SDA=PB7 | 软件 I2C，地址 0x3C |
| 光敏模块 AO | PA4 | ADC1_IN4 |
| 热敏模块 AO | PA6 | ADC1_IN6 |
| TB6612 AIN1/AIN2 | PB0 / PB1 | 方向 |
| TB6612 PWMA | PA8 | TIM1_CH1，1kHz PWM |
| 串口 | PA9=TX，PA10=RX | 115200-8N1（**板载 Type-C 直连，查 PA9/PA10 跳线帽**） |

**电源与安全（实施方案安全条款）**
- 风扇/马达由 **独立 5V 电源**供电，与核心板 **共地**；禁止从核心板取大电流。
- 先检查接线、后上电；OLED/传感器接 3.3V（模块标注 5V 兼容的可接 5V）。

## 2. 开课前套件验收流程（f1-selftest）

1. 每套核心板用 DAP 烧录 `outputs/build/f1-selftest/f1-selftest.elf`（或 hex/bin）。
2. 串口助手 115200 连接板载串口，观察 `[SUM]` 汇总行。
3. 逐项核对（OLED 第 0~7 行同步显示）：

| 子项 | 验收动作 | 通过标准 |
|------|----------|----------|
| LED | 上电观察 | 板载红灯（PA1）1Hz 闪烁 |
| UART | Type-C 直连，打开串口助手（查 PA9/10 跳线帽） | 每秒打印 SUM 行 |
| KEY | 按住板载 KEY1 | KEY 变 OK；蜂鸣器静音 |
| BUZZER | 松开按键 | 0.5s 间歇鸣叫 |
| DHT11 | 等 2s | DHT11=OK，温湿度合理 |
| ADC | 遮光/照光；捏热热敏 | ADC=OK；LIGHT/NTC 数值变化 |
| FAN | 接好 TB6612+风扇 | 5s 一档调速循环 |

全部 OK → OLED 右上角显示 `PASS`，串口显示 `ALL PASS`。登记到《套件验收登记表》。

## 3. 两周实训工程一览（src/projects/）

| 工程 | 对应天次 | 内容 |
|------|----------|------|
| f1-day1-gpio | Day1 | GPIO 点灯 / 按键消抖 / 蜂鸣器 |
| f1-day2-sensors | Day2~3 | DHT11 + 光敏/热敏 ADC（串口输出） |
| f1-day4-oled | Day4 | OLED 显示 + printf 重定向 |
| f1-day5-actuator | Day5~6 | TB6612 风扇 PWM 调速 + 呼吸灯 |
| f1-cabin-thermal | Day7~10 | **联调参考**：智能座舱温控系统（含烟雾/过温→排风扇联动、手动/自动切换） |
| f1-selftest | 开课前 | 套件验收自检固件 |

`f1-cabin-thermal` 控制策略（滞回防抖动）：≥28℃ 开风扇（28~30℃ 线性 20%~80%），
≥30℃ 全速，≥32℃ 过温报警（蜂鸣器 1Hz 断续）；<26℃ 关风扇；光照暗自动开氛围灯。
按键短按：自动↔手动；手动下再短按：0→25→50→75→100% 循环。

## 5. 常见问题

| 现象 | 排查 |
|------|------|
| OLED 全黑 | I2C 接线/地址（0x3C）；换一块排除模块损坏 |
| DHT11 ERR | 检查 PB12、3.3V 供电；读距上一次 <1s 会失败 |
| 风扇不转 | AIN1/AIN2/PWMA 三线是否齐；独立 5V 与共地；STBY 引脚拉高（模块上有） |
| ADC 恒 0 或 4095 | AO 输出脚（非 DO）；模块供电与参考电压 |
| 串口无输出 | 波特率 115200；确认核心板 USB 串口（CH340）驱动 |
