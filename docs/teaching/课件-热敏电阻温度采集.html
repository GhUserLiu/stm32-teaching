③ 感知层 · 热敏电阻温度采集（ADC 配置）

次序：周1（三）3~4　|　产出：实训日志3　| 板卡：野火小智 STM32F103C8T6（初款）　|　参考例程：官方 [21-2]

一句话讲清

热敏是模拟量：温度→电阻→电压，ADC 把电压变成 0~4095 的数字。整条链：分压测电压 → 算电阻 → B 值公式算温度。DHT11 给你"标准答案"，本节自己搭"测量仪"。

接线（3 根）

热敏模块核心板
VCC3.3V（与 ADC 参考电压一致！）
AOPA6（ADC1_IN6，与官方例程 [21-2] 一致）
GNDGND
AO ≠ DO：AO 是连续模拟电压；DO 是模块上电位器设定的开关量（接了读数恒 0 或 4095）。插中间脚前看清丝印。

两步配置（CubeMX）

  1. ADC1 → IN6 勾选（PA6 自动变模拟）
  2. Parameter：Independent mode / 连续转换关（单次轮询） / 采样时间选长（239.5 周期，热敏分压源阻抗高，采样太短读数偏低）

读取与换算（HAL + 公式）

/* 1. 读取（轮询式，最简） */
HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 100);
uint16_t raw = HAL_ADC_GetValue(&hadc1);      /* 0~4095 */

/* 2. 原始值 → 电压 → 电阻（模块内置 10K 定阻与 NTC 分压） */
float v   = raw * 3.3f / 4096.0f;
float r   = 10000.0f * v / (3.3f - v);          /* R_ntc，看模块分压方向 */

/* 3. B 值公式（B=3950，T0=298.15K 即 25℃，R0=10K） */
float t_k = 1.0f / ( logf(r / 10000.0f) / 3950.0f + 1.0f / 298.15f );
float t_c = t_k - 273.15f;
printf("NTC raw:%4d  R:%.0f  T:%.1fC\r\n", raw, r, t_c);
要点说明
均值滤波连读 8 次取平均，消抖（例程 [21-2] 同做法）
方向核对捏热传感器：raw 应单调变化；若公式温度反向 → 模块分压方向与假设相反，R 公式分子分母对调

当堂任务（约 80 min）

  1. printf 输出 raw / 电压 / 温度三列，500ms 一行
  2. 对照定标：与 DHT11 同测一环境，记录两种温度各 10 组（数据进日志3 的表格），计算偏差并分析原因（精度 1℃ vs 连续值、位置差异）
  3. 捏热 / 松开，验证温度连续上升与回落，记录响应大约几秒

三个坑

现象原因
恒 0 或恒 4095接了 DO；AO 松动；VCC 没接
读数偏低不稳采样时间太短（改 239.5 周期）；没做均值
温度方向反分压方向假设反了，对调 R 公式分子分母

官方例程对照（照着做就对了）

配套资料里的工程：《[21-2] ADC多通道采集热敏、光敏、反射传感器（轮询）》。官方主循环（原文，注释里的通道号与本课接线一致）：

HAL_ADCEx_Calibration_Start(&hadc1);       // 上电先校准 ADC（别漏！）

for (int i = 0; i < 3; i++) {
    HAL_ADC_Start(&hadc1);                  // 启动一次转换
    if (HAL_ADC_PollForConversion(&hadc1, 10) == HAL_OK) {
        adc_val[i]  = HAL_ADC_GetValue(&hadc1);
        voltage[i]  = adc_val[i] * (3.3f / 4095);   // 换算电压
    }
}
printf("\r\n光敏(IN4): %.2f V, 反射(IN5): %.2f V, 热敏(IN6): %.2f V\r\n", ...);
要点说明
通道顺序CubeMX 里 Rank 顺序决定读取顺序：官方 光敏IN4→反射IN5→热敏IN6；我们只接 光敏+热敏，把反射通道删掉即可
官方没做的电压→电阻→温度（B 值公式）官方例程停在了电压，本课任务就是补上后半段
