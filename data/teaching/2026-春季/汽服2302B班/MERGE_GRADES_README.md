# 学期成绩册系统说明

## 概述

本系统用于生成汽服2302B班的学期实验成绩册，支持多次实验成绩的合并和汇总。

## 文件说明

### 输入文件

| 文件 | 说明 |
|------|------|
| `data/students.json` | 学生信息（学号、姓名） |
| `data/evaluations.json` | 实验评分数据 |
| `SUBMISSION_TIMES` | 提交时间（内置） |
| `PLAGIARISM_STUDENTS` | 抄弊学生列表（内置） |

### 输出文件

**`汽服2302B班_2026春季学期成绩册.xlsx`**

包含两个工作表：
1. **学期汇总** - 各次实验成绩汇总
2. **实验7-档位模拟器** - 第七次实验详细成绩

## 状态说明

### 学生状态

| 状态 | 说明 | 得分 |
|------|------|------|
| 原创 | 独立完成，未检测到抄袭 | 根据质量评分 |
| 抄袭 | 与他人相似度>80% | 0分 |
| 未完成 | 提交但质量评分过低 | 0分或低分 |

### "实验-未完成"是什么意思？

**"未完成"状态**表示学生提交了实验报告，但由于以下原因被判定为未完成：

1. **内容缺失**：报告缺少必需章节或关键内容
2. **质量过低**：各项得分总和接近0
3. **格式错误**：提交格式严重不符
4. **未实际完成**：只有模板内容，无实际实验结果

**与"未提交"的区别**：
- **未提交**：没有提交任何报告
- **未完成**：提交了但不符合要求

目前第七次实验有 **3人未完成**。

## 数据结构

### 学期汇总表结构

```
| 学号 | 姓名 | 实验1 | 实验2 | ... | 实验7 | 平均分 | 总评 |
```

- 实验1-6：预留（目前为空）
- 实验7：当前已完成的实验
- 平均分：各次实验的平均（目前等于实验7）
- 总评：根据平均分的等级

### 实验7详细表结构

```
| 排名 | 学号 | 姓名 | 提交时间 | 总分 | 等级 | 状态 |
团队协作 | 实验原理 | 实验完成度 | 代码质量 | 报告质量 | 实验态度 |
```

### 评分标准

| 评分项 | 满分 | 说明 |
|--------|:----:|------|
| 团队协作 | 5分 | 成员分工、协作记录 |
| 实验原理 | 10分 | 原理阐述、应用场景 |
| 实验完成度 | 35分 | 硬件设计 + 结果分析 |
| 代码质量 | 30分 | 流程图、代码规范、注释 |
| 报告质量 | 10分 | 问题记录、心得总结 |
| 实验态度 | 10分 | 出勤、操作规范 |
| **总计** | **100分** | |

## 添加新实验

当有新的实验数据时：

1. **准备数据**
   - 更新 `SUBMISSION_TIMES`（提交时间）
   - 更新 `PLAGIARISM_STUDENTS`（抄弊列表）
   - 准备新的 `evaluations.json`

2. **修改脚本**
   - 在 `generate_semester_excel()` 中添加新的实验表
   - 更新学期汇总表的列

3. **运行脚本**
   ```bash
   python merge_grades.py
   ```

## 姓名清理规则

系统自动清理学生姓名，去除：
- 组别前缀（如 "第1组-"）
- 文件扩展名（.docx, .doc）
- 模板后缀（如 "实验报告模板"）
- 无效信息（如 "汽服2302B班-"）

示例：
- `"第2组-陈乐莹"` → `"陈乐莹"`
- `"实验报告模板（郝卓瞳）"` → `"郝卓瞳"`
